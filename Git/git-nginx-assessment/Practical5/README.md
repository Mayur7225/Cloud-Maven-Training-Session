# Practical 5 – GitHub Pull Request Workflow

## Objective
The objective of this task is to understand how pull requests work in GitHub and how developers collaborate using branches.

---

## Step 1 – Create a Feature Branch

A new branch was created to implement a change.

Command:

git checkout -b feature/pr-demo

---

## Step 2 – Add a File

A file named `pr-demo.txt` was created inside the Practical5 folder.

Command:

git add .
git commit -m "Add PR demo file"

---

## Step 3 – Push Branch

The branch was pushed to GitHub.

Command:

git push origin feature/pr-demo

---

## Step 4 – Create Pull Request

A Pull Request was created from `feature/pr-demo` to the `main` branch.

---

## Step 5 – Merge Pull Request

After reviewing the changes, the pull request was merged into the main branch.

---

## Commands Used

git checkout  
git branch  
git add  
git commit  
git push  
git pull  

---

## Conclusion

In this task we learned how developers create feature branches, push changes to GitHub, and merge them using pull requests.
